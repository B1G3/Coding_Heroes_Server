# 스테이지
학습 스테이지

## 스테이지 목표
행동 블록 **이동한다**를 배워보자.

- 사용블록: 이동한다 행동블록, 정수 입력블록
- 사용유닛: 백신 멍멍이

### 이동한다 행동블록
- 이동한다 블록은 **이동할 장소**가 필요해.
- 이동할 장소는 입력블록을 이용하여 지정할 수 있어.

### 정수 입력블록
- 정수블록은 숫자 1부터 지정할 수 있어.
- 만약 정수블록을 이동한다 블록에 연결한다면 그것은 유닛이 이동할 **데이터로드**의 위치를 지정하는 것과 같아.
- 1이 중앙의 데이터로드를 가리키는 것을 시작으로 숫자가 커질수록 시계방향으로 돌면서 데이터로드를 가리켜.

## 자주하는 실수
- 이동블록에 입력블록을 연결하지 않아 유닛이 이동하지 않는다.
